# Up/Down Counter Synthesis

This repository contains the **design and synthesis results of an Up/Down counter** implemented in Verilog and synthesized using Cadence Genus. The project demonstrates RTL design, synthesis, and quality of results (QoR) analysis.

---

## Project Overview

An **Up/Down counter** is a sequential digital circuit that can **increment (count up) or decrement (count down)** its value on each clock cycle based on a control signal. This design is:


- Modular and easy to integrate into larger digital systems  
- Synthesizable for FPGA or ASIC implementation
